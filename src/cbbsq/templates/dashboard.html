Regression spots

Teams that have been lucky tend to come back to earth. Each game below names the side to bet: the team that has been less lucky.

  • Luck edge: how many more points per 100 possessions the team you're betting against has gained from luck this season (points scored and allowed vs. what the shots were worth). Bigger = stronger spot.
  • From opp. misses: how much of that edge comes from opponents missing good shots, which is mostly chance. Positive is better.
  • Last 5: the same edge over the last 5 games. Positive means recent games agree.
  • Click a game for each team's numbers; click a column header to sort. Uses only games before this date. See What's working below for how this pick has done.

What's working

Every signal's picks, graded against the pre-game line at −110. Break-even is 52.4%.

  • Signals: the three luck signals bet the less lucky team (season, opponents' misses only, last 5 games); "all three agree" is the season pick only when the other two point the same way. The two SQ signals turn ShotQuality's pregame SQ projection into a margin and a total and bet whichever side of the line it favors.
  • Edge size: each signal's picks split into thirds, weakest to strongest. A signal that works should win more as the edge grows.
  • ±: the 95% range around the win %. A record is only convincing once the low end clears 52.4%, which takes a few hundred bets.
  • Picks are saved each time you run cbbsq report or cbbsq spots and graded once games are final. Past dates are filled in using only the games before each date.
